# Changelog

All notable changes to Charted are documented in this file.

## [1.0.0] - 2026-09-23

### Added

- Android document capture and image import.
- Linux document image import through the file chooser.
- Local OCR processing on Android with Google ML Kit.
- Local OCR processing on Linux with Tesseract.
- Searchable PDF export.
- Android system save-document dialog support.
- Light and dark mode.
- Clickable project repository link.
- Linux graphical application.
- Linux command-line OCR-to-PDF interface.
- x86_64 Linux AppImage distribution.
- Charted branding and platform application icons.

### Changed

- Android application ID is `com.zentex.charted`.
- Linux application ID is `com.zentex.charted`.
- CLI and Linux OCR default to the English Tesseract language model (`eng`).

### Privacy

- Document images and OCR results are processed locally.
- No document content is intentionally uploaded to a remote service.
